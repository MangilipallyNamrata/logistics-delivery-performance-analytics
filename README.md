# Logistics & Delivery Performance Analytics

## Project Overview
An interactive Power BI dashboard to analyze shipment performance, delivery delays, and shipping status.

## Tools Used
- Power BI
- Data Visualization

## Key Metrics
- Total Shipments
- Average Shipping Delay
- Delay Rate
- Delayed Shipments

## Dashboard Features
- Delivery Status by Shipping Mode
- Delay Rate by Shipping Mode
- Average Delay by Shipping Mode
- Delayed Shipments by Region
- Shipment Delivery Status
- Interactive slicers for Shipping Mode, Market, and Delivery Status

## Project Objective
To analyze logistics performance and identify patterns in shipment delays and delivery status.
